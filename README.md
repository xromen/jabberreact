# Jabber React

Браузерный XMPP-клиент для Openfire с локальной историей, импортом истории Spark и интерфейсом в стиле Discord. Подключение выполняется напрямую из браузера через BOSH/HTTP.

## Запуск

1. В Openfire включите HTTP Binding (BOSH), обычно доступный по адресу `http://SERVER:7070/http-bind/`.
2. При необходимости укажите сервер, порт и путь по умолчанию в `docker-compose.yml`.
3. Запустите приложение:

```bash
docker compose up --build
```

Откройте `http://localhost:18080`. Порт можно изменить переменной `JABBER_HTTP_PORT`. Поле сервера можно изменить при каждом входе. Если XMPP-домен отличается от адреса Openfire, вводите логин как полный JID: `user@xmpp-domain`.

## Локальные данные

История хранится только в IndexedDB текущего профиля браузера. Кнопки `⇧` и `⇩` в панели аккаунта импортируют XML-транскрипты Spark и создают JSON-резервную копию. Пароль не сохраняется.

> Клиент намеренно использует обычный `http://` без TLS. Разворачивайте его только в доверенной сети: логин, пароль и сообщения передаются без шифрования. Openfire должен разрешать CORS-запросы от адреса веб-клиента.
